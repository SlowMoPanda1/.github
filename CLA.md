# Acuerdo de Propiedad Intelectual, Licencia y Confidencialidad (CLA)

El presente documento establece los términos de propiedad, uso y licencias sobre todo el código fuente, infraestructura, scripts y configuraciones desarrolladas por **SlowMoPanda**.

## 1. Definiciones

- **Proyectos Privados**: Todos los repositorios, código fuente, sitios web, bases de datos y servidores gestionados o desarrollados de forma personal por **SlowMoPanda**.
- **Activos**: Cualquier archivo, script (Bash, Python, Lua, etc.), configuración de servidor (Minecraft, Ark, Rust, etc.), documentación o software alojado en esta infraestructura.
- **Titular**: **SlowMoPanda** como creador, desarrollador y administrador único de los proyectos.

## 2. Propiedad Intelectual y Protección de Código

Todo el contenido, lógica de programación, arquitecturas de servidor y scripts son propiedad intelectual exclusiva del **Titular**, salvo que se indique explícitamente lo contrario mediante una licencia de código abierto (Open Source).

1. **Uso Restringido**: Queda prohibida la reproducción, copia, distribución, modificación o ingeniería inversa no autorizada de cualquiera de los Activos.
2. **Confidencialidad**: Toda persona con acceso a los sistemas, repositorios privados o archivos de configuración se compromete a mantener estricta confidencialidad sobre las credenciales, datos y estructura interna del sistema.
3. **Derechos de Gestión**: El **Titular** se reserva el derecho de modificar, revocar el acceso, eliminar o proteger sus Activos mediante las medidas técnicas y legales que considere oportunas.

## 3. Cesión de Contribuciones (CLA)

Cualquier aportación, parche, sugerencia de código o colaboración enviada a los proyectos de **SlowMoPanda** se realiza de forma voluntaria. La contribución no otorga al colaborador ningún derecho de propiedad, copyright, regalías ni licencia exclusiva sobre el proyecto general.

## 4. Acceso Privado y Privilegios

Los servidores de juegos, servicios web y repositorios operan bajo un modelo de **Entorno Privado / Self-Hosted**. El acceso otorgado a amigos o invitados es un privilegio personal revocable en cualquier momento y no constituye una licencia pública de uso.

## 5. Aceptación de los Términos

El acceso a cualquier servidor, repositorio o servicio de **SlowMoPanda** implica la aceptación total de estos términos. El incumplimiento de cualquiera de estas cláusulas supondrá la revocación inmediata de los accesos concedidos.
